Exemplo 2 - Erro lógico: cálculo da média com divisor errado

Erro comum: retornar a soma sem dividir pela quantidade de itens.

function calcularMedia(notas) {
    let soma = 0;

    for (let i = 0; i < notas.length; i++) {
        soma += notas[i];
    }

    return soma; // Erro: não divide pela quantidade
}

console.log(calcularMedia([8, 9, 7]));

Saída: Clique em executar.
